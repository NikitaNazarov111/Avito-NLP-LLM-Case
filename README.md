# Avito_NLP_LLM

Решение задачи поиска объявлений услуг Авито: символьный и словесный TF-IDF, E5 embeddings, учет географии, RRF, CatBoostRanker и валидация Recall@50.

## Поиск объявлений услуг

Для каждого пользовательского запроса нужно выбрать до 50 объявлений из корпуса для дальнейшего ранжирования.

## Подход

1. Нормализация текстов и удаление повторов положительных пар.
2. Символьный TF-IDF по заголовкам и словесный TF-IDF по заголовкам, параметрам и описаниям.
3. Учет совпадения локации запроса и объявления.
4. Смысловой поиск с помощью intfloat/multilingual-e5-small.
5. Объединение результатов через взвешенный RRF.
6. Отбор кандидатов с помощью CatBoostRanker и объединение с поисковыми результатами.
7. Проверка качества на 2 000 отложенных текстов запросов по метрике Recall@50.

## Результат

Лучший локальный Recall@50: **0.719708**.

Лучший Recall@50 на Stepik: **0.773831**.
